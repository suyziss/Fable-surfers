# Запуск Fable Surfers — подробная инструкция

Игра работает в браузере. Node.js нужен только для локального HTTP-сервера, который раздаёт файлы игры. Установка пакетов через npm не требуется: Three.js уже находится в папке `vendor/`.

## Android: Termux

### Установка и запуск

Установи Termux из официального источника, затем выполни:

```bash
pkg update && pkg upgrade
pkg install git nodejs-lts
git clone https://github.com/suyziss/Fable-surfers.git
cd Fable-surfers
node server.cjs
```

Открой браузер на телефоне и перейди по адресу:

```
http://127.0.0.1:43827
```

Оставь Termux работающим, пока играешь. Для остановки сервера вернись в Termux и нажми `Ctrl+C`.

### Запуск через npm

Если предпочитаешь npm:

```bash
npm start
```

### Если порт занят

Запусти сервер на другом порту:

```bash
PORT=43828 node server.cjs
```

Затем открой `http://127.0.0.1:43828`.

### Управление на сенсорном экране

- Свайп влево/вправо — сменить полосу.
- Свайп вверх — прыжок.
- Свайп вниз — подкат.
- Двойное касание — ховерборд (если доступен).

## Windows

Требуется Node.js 20+ (рекомендуется Node.js 22 LTS).

### Способ 1: PowerShell

Открой PowerShell в папке проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Start.ps1
```

Сервер запустится в отдельном процессе, а браузер откроет локальную страницу. Чтобы не открывать браузер автоматически:

```powershell
.\Start.ps1 -NoBrowser
```

Остановка:

```powershell
.\Stop.ps1
```

### Способ 2: командный файл

Дважды щёлкни `Start.cmd`. Для остановки запусти `Stop.cmd`.

### Способ 3: вручную через Node.js

В PowerShell или CMD:

```powershell
node server.cjs
```

Открой `http://127.0.0.1:43827`. Для остановки нажми `Ctrl+C`.

### Способ 4: npm

```powershell
npm start
```

## Linux

Требуется Node.js 20+.

### Способ 1: npm

```bash
npm start
```

### Способ 2: скрипт запуска

```bash
bash start.sh
```

Остановка:

```bash
bash stop.sh
```

### Способ 3: напрямую через Node.js

```bash
node server.cjs
```

Открой `http://127.0.0.1:43827`. Для остановки нажми `Ctrl+C`.

## Частые проблемы

- **Node.js не найден:** проверь `node --version`. Установи Node.js 20 или новее и перезапусти терминал.
- **Адрес не открывается:** убедись, что сервер всё ещё работает и используй тот же порт, который указан в терминале.
- **Порт уже используется:** задай другой порт через переменную `PORT`.
- **Чёрный экран:** обнови браузер, проверь поддержку WebGL и попробуй режим низкого качества в настройках игры, если он доступен.
- **На телефоне медленно:** закрой тяжёлые вкладки и приложения; производительность WebGL зависит от устройства и браузера.

Сервер слушает только `127.0.0.1`, поэтому он предназначен для доступа с того же устройства, где запущен.
