# Components and assets

The character designs, geometry, canvas textures, interface, game logic, musical composition and sound effects were created for this project. No Subway Surfers artwork, models, recordings, trademarks or source code are included. Subway Surfers is referenced only to describe the gameplay inspiration; this project is not an official release.

## Node.js 24.15.0, Windows x64

- Official project: https://nodejs.org/
- Existing installed runtime copied into `runtime/node.exe` for portable local startup.
- Node and bundled dependency license notices are included in `runtime/NODE-LICENSE.txt` from the corresponding official Node.js source tag.

The game makes no requests to external services during normal use. The server binds only to 127.0.0.1. No accounts, paid services or API keys are required.
